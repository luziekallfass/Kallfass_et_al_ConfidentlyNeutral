# Confidently Neutral: Cognitive States of Neutrality in Auditory Perceptual Decisions

This repository will contain the experimental scripts and analysis code associated with the research project:
"Confidently Neutral: Cognitive States of Neutrality in Auditory Perceptual Decisions" by Kallfaß et al. (2026)

Experimental materials and analysis code will be made available upon publication.

## Project Overview
In this project we investigate whether individuals can actively decide to be neutral, meaning that they refrain from choosing either one of a given response alternative, and whether they do so with high confidence.

preprint: https://osf.io/preprints/psyarxiv/z3p95_v3
